# VOID DRIFTER

A space pirate survival game inspired by Oregon Trail. Built with vanilla HTML5 Canvas, JavaScript, and Web Audio API. No external assets or libraries.

## Gameplay

You are a space pirate captain drifting through the void. There is no destination -- only survival. Manage your crew, raid ships, trade at stations, and endure the endless dangers of deep space.

### Resources
- **Fuel** - Consumed during travel. No fuel = adrift
- **Food** - Feeds the crew. Starvation kills
- **Hull** - Ship integrity. Zero = death
- **Oxygen** - Life support. Runs out = suffocation
- **Morale** - Crew happiness. Too low = mutiny
- **Credits** - Currency for trading
- **Ammo** - Needed for combat
- **Ship Parts** - For repairs
- **Reputation** - Lawful to Infamous Pirate (affects encounters and prices)

### Features
- Event-driven travel between procedurally generated star systems
- 16+ random events with meaningful choices
- Trading stations with buy/sell mechanics
- Combat mini-game (dodge and shoot) for pirate encounters and boss fights
- Difficulty scales with distance traveled
- Persistent high score tracking
- Keyboard shortcuts (number keys for choices, Enter to confirm)
- Touch/mobile support

## Controls

### Desktop
- **Mouse** - Hover and click buttons/choices
- **Number keys (1-9)** - Select choices by number
- **Enter** - Select first option
- **Mouse movement** - Dodge in combat

### Mobile
- **Tap** - Select buttons and choices
- **Touch drag** - Dodge in combat

## Running

Open `index.html` in any modern browser. No build step or server required.
